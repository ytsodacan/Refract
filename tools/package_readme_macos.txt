REFRACT - launcher on macOS
===========================

This macOS package includes the Refract launcher shell and UI:
- Meta sign-in
- library browsing
- Quest download/file management

Current limitation
- Running Android games from Refract on macOS is not available yet.

Getting started
1. Unpack this folder somewhere permanent.
2. Start `./Refract`.
3. Use Settings > Setup for environment checks, and Connect Meta to manage your library.
